# Prédiction du risque d'échec virologique

Application développée dans le cadre d'une soutenance de fin de formation en Data
Science, prédisant si la prochaine charge virale d'un patient sous traitement ARV
sera SUPPRIME ou NON SUPPRIME, à partir de son historique de suivi.

Modèle : Random Forest — ROC-AUC (validation temporelle) : voir le notebook d'entraînement.
